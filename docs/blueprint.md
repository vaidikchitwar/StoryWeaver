# **App Name**: Story Weaver

## Core Features:

- Story Display: Display stories in a clean and readable format.
- Story Discovery: Allow users to browse stories by category and search for specific titles or authors.
- Story Creation: Enable users to create and publish their own stories, with basic formatting options.

## Style Guidelines:

- Primary color: White or light grey for a clean reading experience.
- Secondary color: Soft blue or green for highlights and accents.
- Accent: Teal (#330066 for interactive elements.
- Clean and simple layout with clear content hierarchy.
- Use a serif or sans-serif font optimized for readability.
- Simple and consistent icons for navigation and actions.
